# MERAZ 7.0 design system (source of truth)

Generated by ui-ux-pro-max, then filtered. The generator suggested a neon red/blue/green palette on navy, Press Start 2P / VT323 and bento grids. All three were rejected: the brief names its own palette, pixel fonts read as 8-bit arcade rather than Indian print, and bento is too tame for variance 9.

**Design read:** festival marketing site for college students (18-24) across India, loud nostalgic hand-printed language, 70s-90s Indian street print (cinema posters, truck art, railway boards, matchbox labels).

**Dials:** variance 9 / motion 7 / density 5.

## Colour (tokens in `app/globals.css` `@theme`)

| Token | Hex | Role |
|---|---|---|
| cream | #F3E6C8 | page ground |
| ink | #1A1A1A | text, borders, print shadows |
| marigold | #F4A300 | hero ground, secondary buttons |
| turmeric | #F2C14E | text on ink, highlights |
| rani | #E0218A | decoration and large display only (3.57:1 on cream) |
| rani-deep | #B8166F | primary CTA and any text-bearing pink surface (5.0:1 with cream) |
| teal / teal-deep | #0F7C7C / #0A5F5F | teal-deep for text surfaces (6.0:1), teal for art |
| vermillion / vermillion-deep | #D7263D / #B01E30 | deep variant for text surfaces (5.5:1) |

Rule: bright rani, teal and vermillion never carry small text. Use the `-deep` token.

## Type

- Display: Bungee (headings, buttons, labels on posters)
- Poster serif: Rozha One (taglines, ticket titles). Justified: the brief is vintage print
- Devanagari: Yatra One
- Body: Space Grotesk
- Mono / typewriter: Courier Prime

## Shape and depth

- UI controls and cards: sharp corners, 3-4px ink border, hard offset shadow to bottom-right (one light source).
- Physical props (TV, radio, board, projector, corkboard) may be rounded; they are objects, not UI.

## Layout

- Information architecture, buttons and behaviours mirror meraz.iitbhilai.ac.in (see README feature map). Do not add pages or features the reference does not have without asking.
- Home: loader, cinema-screen zoom hero, aftermovie TV, flip menu, fixed REGISTER. Inner pages: Back to Home + poster header.
- Accordions (events, passes) only use flex-basis on md+; on mobile they stack and grow to content.

## Motion

- GSAP ScrollTrigger: pinned hero zoom, pinned TV scale, `[data-reveal]` batch reveals. CSS transitions: curtains, flip button, menu slide, carousel, accordions. Lenis smooth scroll.
- Everything collapses under `prefers-reduced-motion`.

## Deliberate exceptions to the taste ban list

- CRT glow on the loader: part of the CRT TV metaphor.
- Light-only theme: print-emulating palette; `color-scheme: light`.
- Hand-drawn SVG art (skyline, silhouettes, emblems, dancers): requested original artwork. UI icons come from Phosphor only.
